## Worked example

`test_org_dashboard_data.js` is real pipeline output — generated by running:

```bash
python -m framework.cli run --config tests/fixtures/config.test.yaml
```

against the tiny fixture dataset in `tests/fixtures/` (5 people, 2 divisions,
11 sources). It's the same file format the pipeline writes for any config —
copy it (or your own generated `dashboard_data.js`) next to
`ai-engineering-maturity-dashboard.html` and rename it to `dashboard_data.js`
to see the dashboard render from real computed data instead of the built-in
illustrative sample.
